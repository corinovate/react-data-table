# Changelog

## 0.1.0

First release.

- `<DataTable>` with search, multi-column sorting, pagination, column visibility, row and bulk selection, row actions, expandable rows, sticky header, and loading, empty and error states.
- Six themes (`default`, `minimal`, `modern`, `compact`, `dark`, `glass`), `createTheme()`, and `light` / `dark` / `system` color modes.
- Responsive modes: `scroll`, `compact` and `cards`, based on the table's own width.
- Server-side mode with a single `onQueryChange` callback.
- Headless `useDataTable` hook, `Badge` / `renderBadge`, `Pagination`, i18n `labels`.
